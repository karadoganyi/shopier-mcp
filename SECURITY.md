# Security

Please do not report security problems in public issues.

Use GitHub's private vulnerability reporting: https://github.com/karadoganyi/shopier-mcp/security/advisories/new

Never include a real Shopier Personal Access Token or customer data in a report, issue, or pull request. If you have exposed a token, delete it in Shopier under Account > Personal Access Token and create a new one.

Only the latest release is supported.

---

Güvenlik sorunlarını lütfen herkese açık issue olarak bildirmeyin; yukarıdaki özel bildirim bağlantısını kullanın. Bildirimlere gerçek PAT veya müşteri verisi eklemeyin.
